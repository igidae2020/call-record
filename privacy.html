개인정보처리방침 (call-record)

최종 수정: 2026-11-20

call-record는 한 사람(앱 소유자 본인)이 본인 Google 계정에서 본인이 소유한 통화 녹음 파일을 본인 Mac으로 내려받아 전사·요약하는 개인용 도구입니다. 다른 사람의 데이터는 수집·처리하지 않습니다.

접근하는 데이터

  • 본인 Google Drive의 통화 녹음 폴더에 있는 오디오 파일과 파일 메타데이터

보관·전송

  • 파일은 본인 Mac의 로컬 저장소(~data/call-record)에만 보관합니다.
  • 전사는 로컬 Whisper 모델에서 수행합니다. 요약할 때 전사 텍스트만 로컬에서 구동 중인 AI 모델로 보내며, 원본 음성은 외부로 전송하지 않습니다.
  • 제3자에게 판매·공유·재판매하지 않습니다.
  • Google 사용자 데이터 정책과 제한적 사용 요구사항(Google API Services User Data Policy, including Limited Use requirements)을 준수합니다.

삭제

앱 소유자는 언제든 myaccount.google.com의 '연결된 앱'에서 액세스를 취소할 수 있으며, 로컬 데이터는 본인 Mac에서 직접 삭제합니다.
